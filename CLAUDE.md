## RULES

1. Report to me only in ASD-STE100 Simplified Technical English.
2. Check if other agents run parallel tasks. Coordinate with them before you edit a shared file, commit, push, or run any git operation.
3. Keep code changes minimal and simple.
4. For a new feature, write the tests first. Then write the code that satisfies the tests.
5. When the feature is complete, start an independent critic agent. Correct the code until the critic agrees.
6. You can fix a small unrelated bug that you find. Tell me when you do.
7. Never commit or push without my explicit authorization.
